### 안녕하세요 👋

**[PersoDub](https://github.com/stronghamjji/PersoDub)**을 만들고 있습니다. 영상을 다른 언어로 더빙하되,
화자 한 사람 한 사람의 목소리를 그대로 살려서, 내 컴퓨터 안에서 처리하는 데스크탑 앱입니다.

- **목소리 속도 유지**: 다른 도구는 번역이 길어지면 소리를 빨리 돌립니다. PersoDub은 번역을 원래 시간 안에 맞춥니다.
- **목소리 복제**: 내레이션이 아니라, 화자마다 원본 음성에서 음색을 그대로 가져옵니다.
- **앱 하나로 끝**: 더빙, 대본 편집, 자막 지우기, 오디오 분리까지.
- **내 컴퓨터에서 처리**: 계정도 API 키도 필요 없고, 아무것도 올라가지 않습니다.
- **언어**: 내 컴퓨터로 10개, Perso API로 100개 이상.
- macOS(Apple Silicon)와 Windows, AGPL-3.0
