### Hi 👋

I build **[PersoDub](https://github.com/stronghamjji/PersoDub)**, a desktop app that dubs a video
into another language in each speaker's own voice, on your own computer.

- **Keeps the pace**: other tools speed the audio up when a translation runs long. PersoDub fits the translation into the original time instead.
- **Voice cloning, not narration**: each speaker's timbre is cloned from the source audio.
- **One app**: dubbing, script editing, subtitle erasing and audio separation.
- **Runs locally by default**: no account, no API key, nothing uploaded.
- **Languages**: 10 on your computer, 100+ with the Perso API.
- macOS (Apple Silicon) and Windows, AGPL-3.0
